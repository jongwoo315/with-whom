# #155 가져오기에서 공휴일 캘린더 일정을 뺀다 — 설계

## 왜

2026-10-29 jw 아이폰 12에서 가져오기를 한 번 돌렸다. 일정 106개 중 91개가 확인 필요로 갔고,
그중 40개가 공휴일 캘린더 일정이었다(설날 연휴, 삼일절(대체 휴일), 쉬는 날 광복절 등).
공휴일은 누구와 함께한 일정이 아니라 확인 필요 목록만 채운다.

같은 공휴일이 두세 번씩 나온다(「삼일절」, 「삼일절(대체 휴일)」, 「쉬는 날 삼일절」). 공휴일
캘린더가 둘 이상 붙어 있는 것으로 보인다(추정). 어느 캘린더인지, 이름과 종류가 무엇인지는
아직 모른다.

## 정한 것

| 무엇 | 고른 것 | 이유 |
| --- | --- | --- |
| 거르는 방법 | 캘린더 단위로 뺀다. 일정 제목으로 거르지 않는다 | 제목 목록은 해마다 바뀌고(선거일, 대체 휴일) 사람 이름이 든 일정과 섞일 수 있다. 캘린더는 통째로 공휴일이다 |
| 어떤 캘린더를 뺄지 | 설계 §4의 「캘린더 고르기」 화면을 만든다. 처음에는 아래 기본값으로 뺀 상태다 | 어느 캘린더가 공휴일인지 무인 루프가 jw 기기 없이 알 수 없다. 기본값이 놓쳐도 jw가 화면에서 끄면 된다. 회사 캘린더도 같은 화면에서 뺀다 |
| 기본값 | 종류가 `.birthday`·`.subscription`인 캘린더, 이름에 「휴일」·「holiday」(대소문자 무시)가 든 캘린더를 뺀다 | Apple 공휴일 캘린더는 구독 캘린더이고, 구글 공휴일 캘린더(「대한민국의 휴일」)는 CalDAV라 종류로는 안 잡히고 이름으로 잡힌다(추정) |
| 고른 것 저장 | `UserDefaults`에 뺀 캘린더 id 목록. 값이 없으면 기본값을 쓴다 | 다시 만들 수 있는 설정이다. 위젯(#163)이 읽을 일이 없어 App Group에 둘 필요가 없다 |
| 이미 가져온 공휴일 일정 | 가져오기 때 뺀 캘린더의 일정과 `sourceId`가 같은 `Moment`를 지운다 | 지우지 않으면 확인 필요 탭에 40개가 그대로 남는다(지금 upsert는 삭제를 안 한다). 지금 저장된 것은 전부 가져오기로 다시 만들 수 있는 데이터다 |

## 안 고른 것

- 일정 제목 목록으로 거르기 — 위 「거르는 방법」 이유
- `Moment`에 캘린더 id를 저장하고 화면에서 거르기 — 스키마가 바뀌고 화면 셋을 다 고쳐야 한다. 지우는 쪽이 짧다
